# Roll for the Galaxy — Tabletop Simulator assets

Asset host for a repaired build of the *Roll for the Galaxy* Tabletop Simulator
mod. The original mod (2018) hosted all of its 3D models on Pastebin; every one
of those pastes has since been deleted, so no tile, chip or token would load.

These files are referenced directly by the TTS save, so **please don't rename or
delete them** — that is exactly how the original mod broke.

- `models/` — three meshes rebuilt from scratch (square tile, 2×1 faction tile,
  hex victory-point chip), with UVs derived by measuring the texture atlases.
- `textures/` — 107 tile textures, resampled to a canonical artwork box and
  tonally restored.
